# Perfil profesional (input para el prompt de Gemini)

> Este archivo es la "verdad" del matching. Completarlo una vez bien
> hace que el score de Gemini sea útil. Guardar acá la versión que
> después se pega en el system prompt del nodo de IA.

## Datos base
- Rol objetivo: (ej. Full Stack Developer / Data Analyst)
- Seniority: (ej. Junior, 2 años de experiencia)
- Idiomas: (ej. Español nativo, Inglés B2)
- Modalidad aceptada: (ej. Remoto, híbrido CABA)
- Expectativa salarial (opcional, ayuda al score): $X / mes

## Hard Skills
- (lista de tecnologías, ej: React, Node.js, TypeScript, SQL, Docker)

## Conocimientos secundarios
- (ej: AWS básico, Git, Agile/Scrum)

## Experiencia destacada
- 2-3 bullets concretos (ej: "Migré un backend de Express a NestJS...", "Construí un pipeline ETL...")

## Soft Skills
- (ej: comunicación, autonomía, trabajo en equipo)

## Deal-breakers
- (ej: pide 5 años de experiencia siendo junior; paga por debajo del mínimo; uñas garras de staffing mal calificadas)

## Preguntas de sanity-check para el prompt
- ¿Cada skill está escrita como la escribe el marketplace? (ej: "React" no "ReactJS y React.js")
